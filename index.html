How to make a FlippyOS app

FlippyOS turns Flippy's face into a phone. Your app can be on it: players find it in the phone's App Store → Apps, press GET, and use it in the game. First pick which kind you're making.

🌐

Web app

A website shown full-screen on Flippy's phone. No game code: HTML, CSS and JavaScript only.

Icon on the Home Screen
📱

Mod with a phone app

A BepInEx mod that uses FlippyOS: it adds its own app to the phone with a few lines of code (FlippyOSLink.cs), and that app talks to your mod.

Icon on the Home Screen
🧩

Mod

A normal BepInEx mod (new skins, graphics, gameplay…). The App Store just installs it; it doesn't need FlippyOS.

No icon: shows INSTALLED in the store

Rule of thumb: only mods that use FlippyOS get an icon on the Home Screen, and they get it by calling FlippyOSLink, shown below. A mod that doesn't call it still installs fine, it just has no phone app.

🌐 Make a web app

1

Build a page that fits the phone

The phone shows your page at 384 × 313 (CSS pixels, wider than tall). Players move a pointer with the arrow keys and click with Select, and they can type. Use big buttons and big text.

2

Put it online with https

Any host works. GitHub Pages is free: your address looks like https://you.github.io/my-app/.

3

Create the app here

Your apps → New app, kind Web app. Fill in the id, name, tagline, icon, description and install guide, then press Create app.

4

Send a version

Under Versions, type a version number (like 1.0.0), paste your https address and press Send for review.

📱 Make a mod with a phone app

Your app's screen is an HTML page that lives inside your mod's .dll. FlippyOS shows it on the phone, and the page and your C# code send each other JSON messages.

⬇ FlippyOSLink.cs⬇ Hello Flippy example mod (.zip)

1

Copy FlippyOSLink.cs into your mod

Don't change it, and don't reference FlippyOS.dll. If a player doesn't have FlippyOS, your mod still works and just skips the phone app.

2

Load after FlippyOS

Add this line above your plugin class:

[BepInDependency("com.flippyos.fih", BepInDependency.DependencyFlags.SoftDependency)]
3

Make app.html and icon.png, and put them inside the .dll

Keep everything in one HTML file (CSS, JavaScript, pictures as data: URLs), because the App Store installs a single .dll. The icon is a square PNG. In your .csproj:

<ItemGroup>
  <EmbeddedResource Include="app.html" LogicalName="app.html" />
  <EmbeddedResource Include="icon.png" LogicalName="icon.png" />
</ItemGroup>
4

Add your app in Load()

Use the same id as your app here in the portal. That's how the App Store knows your mod is installed and shows OPEN.

public override void Load()
{
    FlippyOSLink.AddApp("my-app", "My App",
        FlippyOSLink.Bytes("icon.png"), FlippyOSLink.Text("app.html"), OnMessage);
}

// everything the page sends arrives here; the JSON you return goes back to the page
string OnMessage(string json)
{
    if (json.Contains("\"ready\"")) return "{\"hello\":\"from my mod\"}";
    return null;
}
5

Talk to your mod from the page

<script>
  // page → mod
  function send(msg) { if (window.flippyos) window.flippyos(JSON.stringify(msg)); }
  // mod → page: what OnMessage returns, or FlippyOSLink.Send("my-app", json) at any time
  window.update = function (data) { document.body.dataset.hello = data.hello; };
  send({ a: "ready" });
</script>
6

Build it, then publish it here

Build your .dll (the example's HelloFlippy.csproj shows how). Then go to Your apps → New app, kind Mod, with the same id. Under Versions, upload the .dll, choose a plugin folder and press Send for review.

Everything FlippyOSLink can do

CallWhat it does
AddApp(id, name, icon, html, onMessage)Puts your app on the Home Screen (or updates it). Returns false when FlippyOS isn't there.
Send(id, json)Sends JSON to your open app's window.update, from any thread.
IsOpen(id)True while the player has your app open.
InstalledTrue when FlippyOS is installed.
Bytes(name) / Text(name)Reads a file you embedded in your .dll.

onMessage runs on the game's main thread, so you can use the game's code there. Keep it quick. Airplane Mode doesn't block mod apps, because they run on the PC.

🧩 Publish a normal mod

Same as step 6 above, without FlippyOSLink: New app, kind Mod, then upload your .dll. Players press GET, restart the game, and the store shows INSTALLED.

✅ What happens after you send a version

  1. Automatic virus check. Every version is scanned by VirusTotal (about 70 antivirus engines). Web apps get their address checked, and mods get their .dll checked.
  2. Nothing found: it's approved automatically and shows up in everyone's App Store within a few minutes.
  3. Something flagged: it waits, and the store's admin checks it by hand. If it's rejected, the reason shows next to your version.
  4. Updates are new versions (like 1.0.1), checked the same way. An approved file can never be swapped.

Rules: no malware, no stealing accounts or data, nothing that breaks other mods or the game's online play. Apps that break them are removed.
